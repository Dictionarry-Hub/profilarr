A vulnerability was identified in the reverse-proxy handling code paths on
versions prior to **2.3.0**. The fix is already shipped in 2.3.0 and patched
into `:latest`.

**Action**: upgrade as soon as possible. If you cannot upgrade, block
unauthenticated access at the proxy layer until you do.

Full details and CVE reference in the [security advisory](https://github.com/Dictionarry-Hub/profilarr/security).
