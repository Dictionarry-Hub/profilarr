## What's changing

The legacy `/api/v0/*` endpoints are deprecated and will be removed in the 2.4
release, expected June 2026. The replacements live at `/api/v1/*` and follow a
stable OpenAPI contract.

## What you need to do

- Update any scripts or dashboards hitting `/api/v0/*` to their `/api/v1/*`
  equivalents.
- If a specific legacy endpoint has no v1 replacement yet, open an issue and
  we'll prioritise it before 2.4 lands.

## Timeline

- **2.3.x**: legacy routes still work, logged as deprecated.
- **2.4.0**: legacy routes return 410 Gone.
